# 🏁 RFID Race Timing System

A Raspberry Pi-based RFID timing system for:
- Cross Country
- Cycling
- Solo training

## Features
- Live leaderboard
- Lap tracking
- Split timing
- Mobile-friendly UI
- Offline hotspot mode

## Hardware
- Raspberry Pi 4
- UHF RFID reader (EPC Gen2)
- UHF RFID antenna
- RFID bib tags

## Run
```bash
pip install -r requirements.txt
python app.py
